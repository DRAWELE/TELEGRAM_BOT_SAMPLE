# TELEGRAM_BOT_SAMPLE

Host it on render.com
- Create repo on github
- add these files to your repo
- create a new web service & fetch that repo with render.com 
- paste these build and start commands at settings
- go to the https://uptimerbot.com
- add your project.onrender.com URL to a monitor and set interval second as 5 Minutes

Build command:
```
npm install
```

Start command:
```
node index.js
```
